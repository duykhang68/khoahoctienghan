# Engineering Culture 2.0

Status: proposed in engineering PR; validate CI and production before marking active.

One logical PR; atomic branch commits; squash merge into main via GitHub native strict required checks. Intermediate red commits need not be replayed. Independent PRs may merge without previous deployment; dependent work waits for its prerequisite. Sensitive workflow/automation/security/dependency changes are explicitly reviewed; never auto-merge forks or Dependabot.

Three workflows: read-only CI checks content, secret patterns, regression, build, and Chromium desktop/mobile; CI on current main produces a release artifact containing exact SHA; CD selects current main with successful CI, downloads only its trusted artifact, serializes Pages deploy, rechecks freshness just before deploy, verifies exact SHA and public routes. A stale candidate is SUPERSEDED; a missing green main is DEFERRED. No previous-release FIFO gate. Engineering feedback loop handles safe known fixes, bounded transient retry, unknown/semantic conflicts via researcher and deduplicated issues. Event-driven plus hourly reconciliation. GitHub token-originated merges explicitly dispatch main CI; manual CD dispatch is recovery if event missed. A real failed production release is investigated rather than blindly retried.

Repository settings (owner action once): run scripts/configure-repository.sh using authenticated gh CLI after this PR has green CI. It enables strict main rules, native auto-merge, squash-only history, delete merged branches and secret scanning/push protection. It refuses to replace existing rulesets. Controller automatically invokes GitHub's immediate squash merge for only a trusted exact green PR; never --admin and never leave auto-merge armed for future unreviewed edits. Native gate protects normal pushes, but sensitive changes still need explicit review in this solo-owner repository. Enable Dependabot alerts/dependency graph in Security settings if absent. Version updates are PRs, never automatically merged by controller.

Supply chain: package-lock.json is generated by npm and committed; npm ci is mandatory in CI, full action commit pins, weekly Dependabot. Secret pattern check is not a full secret scanner. No credentials in repo, public issues or artifacts. No claim of zero bugs. Review the fixed-SHA CI/CD results, real production URLs and actual browser output before closing incidents.
