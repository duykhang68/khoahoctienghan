# AWS-inspired Tech Blog component system
Reference article: https://aws.amazon.com/blogs/architecture/how-tui-scales-threat-modeling-for-100-teams-with-amazon-bedrock/
Index: https://aws.amazon.com/blogs/architecture/
Visual token cross-check (unofficial): https://www.shadcn.io/design/aws

The reference's indexed article confirms title, byline/date/category, Permalink and Share, and the Architecture index confirms the separate Blogs navigation and chronological editorial feed. Direct rendered article/CSS access was unavailable; this implementation reconstructs that structure rather than claiming pixel equivalence. Use independent Tri thức Hàn Quốc identity and actual local destinations, not AWS branding marks, account or sales controls.

Tokens: #161d26 navigation/headings, #232b37 body text, #0972d3 primary/link, #003b8f hover, #f3f3f7 soft surface, #ccccd1 borders, white reading surface. Use the owner-provided Ember webfonts and Open Sans fallback for missing Vietnamese glyphs. Keep prose justified; link lists and metadata naturally aligned. Search submits, category dropdown, breadcrumb, permalink/share, navigation and footer work without remote JS/CSS. Scope: Tech Blog only; no Knowledge Base, content, CI/CD or font asset changes.
