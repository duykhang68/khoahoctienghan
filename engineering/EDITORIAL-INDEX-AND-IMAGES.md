# Editorial index and image treatment
References: https://www.anthropic.com/engineering and https://www.figma.com/blog/how-figma-manages-sandboxes-at-scale/

The current indexed Anthropic page exposes an engineering introduction, featured stories, article count, most-recent ordering, grid/list view and a See more action. Adopt that information architecture in /techblog/ only, with a single newest feature rather than pinned editorial picks; every article remains in the chronological archive. Shared AWS navigation and reading layout remain; typography is Source Sans 3 / IBM Plex Mono (see TYPOGRAPHY.md). A responsive 3/2/1-column grid, warm neutral surface and spacing are original adaptations; no live rendered CSS or pixel comparison was available.

The indexed Figma source describes a conceptual editorial lead illustration, technical diagrams, and charts with captions. Adopt meaningful, article-specific images, full-content presentation without destructive cropping, a stable 16:9 frame, descriptive alt text and optional visible captions. Prefer original local WebP artwork for future covers. All three existing posts lacked covers at implementation time. CSS-only decorative card motifs are original placeholders, not claims of actual article diagrams. Do not hotlink or copy Figma/Anthropic art. Real cover images replace placeholders automatically. On article pages retain AWS layout; only cover frame/optional caption styling changes. No modifications to post content or KB.
