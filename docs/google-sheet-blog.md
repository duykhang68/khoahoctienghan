## Setup
Reuses the existing Reddit Editor production OAuth Web application public client ID, verified from the plain-text GOOGLE_CLIENT_ID configured on Cloudflare Pages. The default is in src/lib/sheet-blog/oauth-config.mjs; PUBLIC_GOOGLE_SHEETS_CLIENT_ID is an optional deployment override. No manual Client ID entry in the normal UI. In the existing Google Cloud OAuth client, ensure Authorized JavaScript origins includes https://duykhang68.github.io (origin only, no path), without removing the existing Reddit Editor origin. Enable Google Sheets API and configure consent/test users as required. Cloudflare configuration confirms the client ID, not the Google Cloud origin allowlist; real OAuth must still be verified. Google OAuth account itself needs access to this spreadsheet. Sharing with blognaver-articlepdf service account does not grant the browser user access or produce a user OAuth client ID. Never place service-account JSON/private key or OAuth client secret in a public repo or webpage. A service-account-backed single-login flow requires an authenticated server with its own credentials; this static page intentionally does not implement one. GitHub owner fine-grained token (Contents read/write for this repo) is required separately and kept only in memory. Google token is also memory-only. Disconnect clears page state, not prior OAuth consent at Google. Official GIS script is loaded directly from Google per its documented requirement; browser scripts and extensions remain a trust boundary. Only the public OAuth client identifier is committed; no secrets, tokens or actual Sheet content are committed by this feature. All live data is retrieved after login. Browser CI uses synthetic fixtures only; real OAuth settings and end-to-end publication need owner verification.

References: https://developers.google.com/identity/oauth2/web/guides/use-token-model ; https://developers.google.com/workspace/sheets/api/reference/rest/v4/spreadsheets.values/get.
