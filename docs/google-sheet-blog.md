## Setup
Create/choose a Google OAuth Web application client with authorized JavaScript origin https://duykhang68.github.io; enable Google Sheets API, configure consent/test users as required. Public client ID can be supplied in the UI and remembered locally (not a secret), or set PUBLIC_GOOGLE_SHEETS_CLIENT_ID in Astro build environment. Google OAuth account itself needs access to this spreadsheet. Sharing with blognaver-articlepdf service account does not grant the browser user access or produce a user OAuth client ID. Never place service-account JSON/private key or OAuth client secret in a public repo or webpage. A service-account-backed single-login flow requires an authenticated server with its own credentials; this static page intentionally does not implement one. GitHub owner fine-grained token (Contents read/write for this repo) is required separately and kept only in memory. Google token is also memory-only. Disconnect clears page state, not prior OAuth consent at Google. Official GIS script is loaded directly from Google per its documented requirement; browser scripts and extensions remain a trust boundary. No credentials or actual Sheet content are committed by this feature. All live data is retrieved after login. Browser CI uses synthetic fixtures only; real OAuth settings and end-to-end publication need owner verification.
