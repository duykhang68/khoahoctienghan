# P1.10 · Server Scheduler (disabled until reviewed and configured)

This is a security-sensitive continuation of P1.9. It stores the explicitly consented immutable Editor V2 snapshot in a private D1 database, not GitHub, until due. Local drafts and local browser schedules remain separate; cancel any existing device schedule for an article before switching. The server page is /admin/schedules/. No PAT, browser session or Google token is needed after scheduling. Scheduled time is earliest FIFO submission, not guaranteed production time. Cron ticks every minute, handles a single due head, uses atomic lease and digest checks, retries temporary failures at most 3 attempts; blocks on unresolved receipt/permission/validation failure. Waits for matching trusted bot Issue before advancing. Cancellation is only safe before first attempt. Explicit retry uses the same immutable bytes. D1 payload chunks are deleted after receipt or cancellation; D1 backups/time travel can retain historical copies per Cloudflare retention. No hidden migration of local drafts.
