# P2.5 Drive media
Owner uploads directly into configured private My Drive folder; Service Account uses drive.readonly and server-side JWT exchange. Only direct children with supported playable MIME, explicit download capability, not trashed. No shortcuts, external URL, nested traversal, upload/delete on Drive, or public links. Up to 500 listed direct children and 30 linked files per lesson. Owner-only preview streams through authenticated Worker with single Range forwarding, no-store and membership/revalidation; native browser codec support required. Metadata links only in dedicated COURSE_DB. Unlink never deletes Drive files. Configure GOOGLE_SERVICE_ACCOUNT_JSON as existing secret and COURSE_MEDIA_FOLDER_ID as plain binding during reviewed exact-main Worker release. Apply course-media-migration.sql after P2.3 and P2.4. Real auth verification: open media page as owner and confirm Drive connected; empty folder is legitimate; upload valid MP4/MP3 to exercise playback. No public streaming/student access. Captions/transcript and nested folder support deferred. Official references: https://developers.google.com/identity/protocols/oauth2/service-account and https://developers.google.com/workspace/drive/api/guides/manage-downloads .
