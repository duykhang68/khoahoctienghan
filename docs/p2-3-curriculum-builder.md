# P2.3 Curriculum Builder

Private route /admin/courses/:id/curriculum/ from draft Course Management card. Chapters and lessons have stable UUIDs, editable names, ordered arrays; drag handles and keyboard-accessible up/down buttons, select for moving lessons across chapters. One explicit save; unsaved navigation warning. Single versioned D1 JSON row per course; conditional write is atomic and permitted only for draft courses. Existing IDs cannot be deleted in this phase; lessons have no body/media yet. Limits 100 chapters, 500 lessons, 200-character titles, 256 KiB requests. No public content or changed P2.2 data. Apply course-curriculum-migration.sql once to COURSE_DB after P2.2 and verified main; no migration on scheduler DB. Native CI and authenticated owner UAT pending.
