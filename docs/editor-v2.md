# Editor V2 — independent online Editorial Studio

URL after production verification: /khoahoctienghan/techblog/editorv2/. Implements a standalone Astro and browser JavaScript block editor with the shared public editorial design tokens. No V1 imports, localhost server, Codespaces, separate hosting, workflow secrets or dependency changes. Currently supports new articles, per-block formatting, notes, tables, images converted to WebP (max dimension 1600), reordering, approximate preview, browser-local draft and downloadable backup. Existing article edits, scheduling, selection-level formatting, synced drafts and full Visual Editorial 2.0 diagrams are not implemented.

The page is publicly visible, but writes need the owner's fine-grained PAT scoped only to this repository (Contents and Pull requests read/write); GitHub verifies permissions, browser code additionally checks owner login. Never enter credentials in chat or source, nor use a broad PAT. The token is held only in memory until logout/reload; like any browser-only editor this is not a server-side secure session and same-origin scripts or browser extensions are a risk. Use a short expiry and revoke when not needed. All requests go to api.github.com; no token in draft storage, export, URL or error handling. Publishing requires explicit confirmation and creates a separate branch and Draft PR, never writes main. GitHub native CI validates the resulting content. No real token required for CI; public browser test does not publish.

Uses the same canonical Astro content schema (structured StudioDocument, metadata index, Tech Blog JSON, WebP content-addressed asset rules) independently from V1. No manual Markdown editing required. Drafts are separate from V1. Existing URLs remain unchanged.
