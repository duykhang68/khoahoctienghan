# Course Management Studio 2.0 — P2.2
Design references: supplied Linear workspace image, https://linear.app/docs/display-options, https://linear.app/docs/filters. Neutral dense workspace, restrained pastel status accents, no copied proprietary code.
Architecture: core.mjs is pure shared normalization, validation, labels, filtering, sorting, statistics, action policy and state transitions. route.mjs is server I/O and existing guarded mutation; view.mjs assembles private page and nonce-bound browser functions; styles.mjs owns scoped tokens; render.mjs handles DOM table/grid/inspector; browser.mjs owns fetch, dialog, toast and lifecycle. Browser code is served only by the authenticated management page; no public build paths changed. Worker entry keeps auth and routing, imports these modules (deployment must include the complete import graph).
List cap: 100 latest courses, 20/page locally; summary counts all courses. Date filter uses GMT+7 updated date. No enrollment, fees, history fabricated or permanent deletion. Slug immutable once created; 409 preserves input, compares newest loaded row and requires explicit replacement, never silently rebases. Native dialogs provide focus containment and Escape, reduced motion; initial SSR loads D1 synchronously, skeleton only during refresh.
Validation: existing mandatory CI plus Playwright integration with isolated SQLite, six widths and pure core regression. Actual production owner UAT and before/after screenshots require browser evidence; do not claim before available.
