# P2.4 Visual Lesson Editor

Private editor from each saved curriculum lesson. Direct visual editing (plaintext-only contenteditable blocks), heading/subheading, paragraphs, notes, quotes, ordered/unordered lists, dividers, local image optimization, accessible controls, live preview and explicit save. No handwritten Markdown, raw HTML, external image URLs, public course material or payment. Shared editor-v2 media contract: PNG/JPEG/WebP/GIF input, normalize to WebP max 1600 px with required alt. D1 stores private versioned JSON per lesson; whole document cap 1.5 MB (including base64 image bytes), stricter than individual shared-media cap, so larger/multiple images require optimization or later private media storage. No paid storage provision. Atomic conditional write guards course draft status, curriculum membership and current document version. Apply course-lesson-migration.sql once after P2.3 migration in reviewed exact-main release. No production changes in PR. Rich inline marks, video/audio and quiz are not implemented in this PR. Native CI and owner UAT pending.
