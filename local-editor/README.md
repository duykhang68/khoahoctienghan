# Trithuchanquoc Editor (localhost)

From an updated checkout: `npm ci`, then `npm run editor` (Node 24+). Open http://127.0.0.1:4317. Server listens on loopback only. It reads tracked content at local Git HEAD without network access. Drafts are kept in this browser's localStorage (not written into source files or Git automatically). Export/copy important drafts before clearing browser storage.

Content: browse Markdown/MDX docs, create a new Markdown lesson, edit existing frontmatter/body, edit Tech Blog JSON or individual post JSON, and edit a Visual Editorial catalogue if present. Plain text preview does not execute arbitrary MDX. Menu: edit sidebar titles and internal route links, add/delete menu entries or groups, drag to reorder within a group or at top level, keyboard-friendly up/down controls. Existing sidebar is migrated from autogenerate to explicit menu JSON; add new lesson links manually. Homepage topic content remains separate. Links omit project base; mandatory home and Tech Blog destinations stay canonical. No deletion of published articles in this initial editor.

GitHub: fine-grained PAT (repository duykhang68/khoahoctienghan only, Contents read/write, Pull requests read/write, Metadata read). Connect validates identity and repository push access; token only server RAM, not saved, never appears in URLs. Disconnect or stop server to discard token. Pull reads a fixed main SHA. Draft edits are retained; conflicting paths block sync until reconciled manually. Sync validates content/menu, compares each file hash against remote, creates one commit on a new content/editor-* branch and one PR, not a main commit. No auto-merge bypass, no production claim. Pull after successful merge to retire identical drafts. If PR creation fails after branch creation, inspect branch before retrying. Manual sync only; no polling. Use local editor on a trusted machine; do not expose port via tunnel. Public site does not include editor assets.

Reference: https://docs.github.com/en/rest/guides/using-the-rest-api-to-interact-with-your-git-database
