# P0.1 — Back Office & Security Foundation

Option B: Google Identity Services (OIDC), Cloudflare Worker, no Zero Trust. No Google client secret required for ID-token sign-in. Existing Sheets client ID can be reused without changing existing origins. Add `https://korean-backoffice.tamsudev-com.workers.dev` to authorized JavaScript origins in Google Cloud Console. Prefer a dedicated client if sharing consent settings is undesirable.

Configure Worker bindings GOOGLE_CLIENT_ID, BACKOFFICE_ORIGIN (exact HTTPS origin), ADMIN_EMAILS (owner-confirmed Google email allowlist), and SESSION_SECRET (separate cryptographically random secret, >=43 characters; never commit). Deploy only after security review and CI. Server verifies Google signature, issuer, audience, expiration, nonce, verified email and allowlist. Same-origin login/logout, signed HttpOnly Secure host-only cookies, 8h absolute lifetime. Logout clears local cookie; a stolen session remains valid until expiry or secret rotation. No Google Sheets access token granted by admin login; retain independent least-privilege sheet authorization. No automatic sign-in. Preview and other origins fail closed. Before migrating dashboard and Google Sheets publisher, verify authorized/unauthorized Google account, direct routes, logout, and public site. Move actual admin code out of GitHub Pages build; do not publish #106 as a public page. P1 remains blocked until verified. Run `node --test back-office/worker.test.mjs`.

References: https://developers.google.com/identity/gsi/web/guides/verify-google-id-token and https://developers.google.com/identity/gsi/web/reference/js-reference.
